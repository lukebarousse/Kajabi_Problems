Problem Statement

As a data engineer, you need to establish a system for tracking high-priority skills within job postings. Your objective is to create a dedicated table for prioritized job skills and populate it with active records by cross-referencing the general skills dimension with a specific priority staging table.

Task

  • Create a SQL file in the Lesson folder named 1.23.2.sql.
  • Write a CREATE TABLE statement to define the main.job_skill_priorities table with the following schema: job_id (INT), skill_id (INT), skill_name (VARCHAR(50)), priority_lvl (INT), and status (VARCHAR(20)).
  • Write an INSERT INTO statement to populate the job_id, skill_id, and status columns of the new table.
  • Use a SELECT statement with an INNER JOIN between data_jobs.skills_job_dim and staging.priority_skills on the skill_id column to retrieve the relevant data.
  • Hardcode the value 'ACTIVE' for the status column in your selection to indicate the current state of these records.

Hint

  • To execute your query in the file, select the entire statement, including the final ; and use the keybinding defined in the lesson (i.e., Shift+Enter).
  • Remember that an INNER JOIN only returns rows where there is a match in both tables. This effectively filters out any job skills that are not present in your priority list.
  • When using INSERT INTO with a SELECT statement, ensure the order of columns in your SELECT clause matches the order of columns specified in the INSERT INTO parentheses.
