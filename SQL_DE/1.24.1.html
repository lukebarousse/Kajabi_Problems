Solution

  1. Connect to the shared data_jobs DuckDB database from your terminal 
    duckdb md:data_jobs
  2. Create the staging.priority_skills table. 
    CREATE TABLE staging.priority_skills (
  skill_id INT PRIMARY KEY,
  skill_name VARCHAR(50),
  priority_lvl INT
);
  3. Insert records for Python, SQL, and Tableau with their respective priority levels. 
    INSERT INTO staging.priority_skills (skill_id, skill_name, priority_lvl)
VALUES 
  (1, 'python', 1),
  (0, 'sql', 1),
  (183, 'tableau', 2);

Explanation

  • Connect to data_jobs: duckdb md:data_jobs opens a DuckDB session pointing at the shared data_jobs database.
  • Table Definition: The CREATE TABLE statement defines the structure of staging.priority_skills.

    Defining a schema ensures data types are consistent across the pipeline.

    • The skill_id is the PRIMARY KEY, ensuring every row has a unique identifier.
    • The skill_name uses VARCHAR(50) for text storage.
    • The priority_lvl uses INT for numeric ranking.
  • Data Population: The INSERT INTO statement adds the actual records.

    By listing the columns explicitly, we ensure the data maps correctly even if the table is altered later.
