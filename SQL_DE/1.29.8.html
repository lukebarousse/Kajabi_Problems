Solution

  1. Connect to the shared data_jobs DuckDB database from your terminal 
    duckdb md:data_jobs
  2. Run a query to identify job postings with missing company information and standardize those names to 'UNKNOWN' using a left join and the COALESCE function. 
    SELECT 
    j.job_id,
    UPPER(COALESCE(c.name, 'Unknown')) AS company_name_standardized
FROM 
    job_postings_fact AS j
LEFT JOIN 
    company_dim AS c ON j.company_id = c.company_id
WHERE c.name IS NULL;

Expected Outcome

Explanation

  • Connect to data_jobs: duckdb md:data_jobs opens a DuckDB session pointing at the shared data_jobs database so all queries run against that dataset.
  • Join Logic:

    The query uses a LEFT JOIN to combine job_postings_fact (aliased as j) with company_dim (aliased as c) using the company_id as the common key. This ensures we keep all records from the job postings table even if matching company details are missing.

  • Data Cleaning with COALESCE:

    We use the COALESCE function to handle NULL values in the name column. This function evaluates the arguments in order and returns the first non-null value; if c.name is missing, it defaults to the string 'Unknown'.

  • Standardization with UPPER:

    The UPPER function is wrapped around the COALESCE result to ensure that all output in the company_name_standardized column is in capital letters, providing a consistent format for reporting.

  • Filtering Results:

    The WHERE clause specifically filters for rows where c.name IS NULL. This isolates the specific job postings that are missing associated company metadata in the dimension table.
