Solution

  1. Connect to the shared data_jobs DuckDB database from your terminal 
    duckdb md:data_jobs
  2. Run a query to select the job_id and provide a default value of 'Remote' for missing job_location entries using the COALESCE function. 
    SELECT 
    job_id,
    COALESCE(TRIM(job_location), 'Remote') AS location_clean
FROM 
    job_postings_fact
WHERE 
	  TRIM(job_location) IS NULL;

Expected Outcome

Explanation

  • Connect to data_jobs: duckdb md:data_jobs opens a DuckDB session pointing at the shared data_jobs database so all queries run against that dataset.
  • Handling Missing Values: The query uses the COALESCE function to manage NULL entries in the dataset while ensuring data consistency.

    • The TRIM() function is applied to the job_location column to remove any leading or trailing whitespace that might exist in the raw data.

    • The COALESCE() function evaluates the trimmed location. If the result is NULL, it returns the specified fallback value, 'Remote', which is then aliased as location_clean.

  • Filtering Criteria: The WHERE clause is used to narrow down the records from the job_postings_fact table.

    • By filtering with WHERE TRIM(job_location) IS NULL, the query specifically targets rows where the location information is missing, allowing us to observe how the COALESCE function replaces those NULL values in the final output.
